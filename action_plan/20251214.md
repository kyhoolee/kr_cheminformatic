Để đặt tên module cho tiện (concise), dễ nhớ (semantic) và tránh xung đột với thư viện chuẩn của Python (như `json`, `io`, `csv`), mình gợi ý bạn theo phong cách **"Noun-Verb" (Danh từ - Động từ)** hoặc **Functional Naming**.

Vì bạn muốn import trực tiếp từ root và dùng chung cho nhiều dự án con (`_1_patent_detect`, `_2_docking`), chúng ta cần một cái tên cho folder dùng chung (Shared Library) thật ngắn gọn.

Mình đề xuất tên folder dùng chung là **`chemcore`** (hoặc `chem_utils`).

Dưới đây là gợi ý naming cụ thể cho các file `.py` bên trong:

### 1\. Cấu trúc thư mục & Naming

```text
kr_cheminformatic/
├── chemcore/                 <-- [SHARED LIB] Tên ngắn, dễ gõ
│   ├── __init__.py
│   ├── io.py                 <-- (Ko nên) Dễ trùng tên module io của Python
│   ├── loader.py             <-- [CHỌN] Chuyên để load/read data (CSV, SDF, GZ)
│   ├── prep.py               <-- [CHỌN] Pre-processing (Clean, Norm, Salt remove)
│   ├── fingerprint.py        <-- [CHỌN] Tạo index/fingerprint (Morgan, MACCS)
│   ├── sim.py                <-- [CHỌN] Similarity search (Tanimoto logic)
│   └── viz.py                <-- [CHỌN] Visualization (Vẽ cấu trúc)
│
├── _1_patent_detect/         <-- [PROJECT 1]
│   ├── scripts/
│   │   ├── 1_ingest.py       <-- Đánh số để biết thứ tự chạy
│   │   ├── 2_index.py
│   │   └── 3_search_poc.py
│   └── ...
```

### 2\. Tại sao chọn tên này? (Chiến lược Import)

Cách đặt tên trên sẽ giúp câu lệnh import của bạn đọc lên như một câu văn tiếng Anh dễ hiểu:

**Ví dụ 1: Khi cần Load dữ liệu**

```python
# Thay vì: from cheminformatic_library.data_ingestion import read_file
# Dùng:
from chemcore import loader

df = loader.read_chembl_gz('data/raw/chemreps.txt.gz')
```

**Ví dụ 2: Khi cần Xử lý hóa học (Normalization)**

```python
# Thay vì: from normalization_module import standardize_smiles
# Dùng:
from chemcore import prep

# Đọc rất thuận miệng: "Use prep to clean structure"
mol = prep.clean_structure(smiles_string)
```

**Ví dụ 3: Khi cần Search**

```python
from chemcore import fingerprint, sim

fp1 = fingerprint.get_morgan(mol1)
fp2 = fingerprint.get_morgan(mol2)
score = sim.calc_tanimoto(fp1, fp2)
```

### 3\. Chi tiết nội dung gợi ý cho từng Module

Để bạn dễ hình dung và copy vào làm luôn, mình mô tả chức năng của từng file:

#### `chemcore/loader.py` (Data Ingestion)

Chứa các hàm I/O. Tránh đặt tên là `io.py` vì Python có sẵn thư viện `io`.

  * `read_sdf_gz(path)`
  * `read_smiles_csv(path)`
  * `save_to_pickle(obj, path)`

#### `chemcore/prep.py` (Preparation / Normalization)

Đây là nơi chứa logic RDKit để làm sạch. Tên `prep` ngắn hơn `normalization` và bao hàm nghĩa rộng hơn (chuẩn bị dữ liệu).

  * `to_mol(smiles)`: Chuyển string sang RDKit Mol (có xử lý lỗi).
  * `strip_salts(mol)`: Loại bỏ muối (Ví dụ: `Na+`, `Cl-`).
  * `canonicalize(mol)`: Chuẩn hóa cấu trúc.

#### `chemcore/fingerprint.py` (Indexing)

  * `gen_morgan_fp(mol)`: Tạo Bit Vector để search nhanh.
  * `gen_maccs_keys(mol)`: Tạo key đơn giản hơn.

### 4\. Áp dụng vào Repo của bạn ngay bây giờ

Bạn có thể chạy các lệnh sau để đổi tên và setup cấu trúc này:

```bash
# 1. Tạo folder shared lib
mkdir chemcore
touch chemcore/__init__.py

# 2. Tạo các module rỗng
touch chemcore/loader.py
touch chemcore/prep.py
touch chemcore/fingerprint.py

# 3. Di chuyển file code cũ (nếu có) vào đúng chỗ
# Ví dụ bạn đang viết dở phần load file, hãy move code đó vào chemcore/loader.py
```
